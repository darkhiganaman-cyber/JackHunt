# JackHunt — Halloween plugin for Paper 1.21.x

Плагин запускает охоту за уникальной головой Джека в мире Overworld. Первый игрок, подобравший голову активного раунда, получает +1 постоянное очко.

## Требования
- Java 21
- Paper 1.21.x (проект собирается против Paper API 1.21.4)
- Maven 3.9+

## Сборка
В корне проекта:
```bash
mvn package
```
Готовый файл: `target/JackHunt.jar`

Скопируйте JAR в `plugins/` и перезапустите сервер. При первом запуске появится `plugins/JackHunt/config.yml`.

## Команды
- `/jack` — справка
- `/jack start` — запустить раунд сейчас
- `/jack stop` — остановить и удалить активную голову
- `/jack top` — топ-10 игроков
- `/jack points <ник>` — очки онлайн-игрока
- `/jack setcenter` — установить центр поиска на текущие X/Z
- `/jack reload` — перезагрузить конфиг

Админские команды требуют `jackhunt.admin` (по умолчанию OP). `/jack top` доступна всем.

## Настройка
- `world`: имя мира, обычно `world`
- `min-radius` / `max-radius`: радиус относительно центра
- `interval-minutes`: пауза между раундами после победы/тайм-аута
- `round-timeout-minutes`: сколько голова лежит в мире
- `location-attempts`: число попыток найти безопасную точку

Точки выбираются только в уже сгенерированных чанках, чтобы не запускать массовую генерацию мира. Если точка не найдена, плагин повторит попытку позже.

## Важные ограничения первой версии
- Очки и конфигурация хранятся в `config.yml`; для очень больших сетей или частых записей лучше перейти на SQLite.
- `setcenter` задаёт центр по текущим X/Z. Для корректной работы установите его в Overworld.
- Плагин не интегрирован автоматически с WorldGuard/приватами; при необходимости добавьте проверки регионов.
- Перед установкой на основной сервер протестируйте на копии мира.
